COG — THE WEAKEST LINK · OFFLINE CLASSROOM EDITION

HOW TO START ON WINDOWS
1) Extract this folder from the ZIP.
2) Double-click index.html (use Chrome or Edge).
3) Connect the computer to a projector and press FULL.
4) Leave the default 8 pairs (16 learners), or enter between 2 and 20 pairs.
5) Edit pair names, choose round length and press START THE SHOW.
6) Press START TIMER when ready to ask questions out loud.

TEACHER CONTROL
- Read the on-screen question aloud.
- Listen to the contestant's oral answer.
- C = mark CORRECT; X = mark INCORRECT (strong green/red visual and sound).
- N or NEXT QUESTION = advance and rotate to the next pair.
- B or BANK = save the current chain before judging the next answer.
- SPACE = pause/resume the round timer.
- End of round = collect votes orally; you register votes and select which pair is eliminated.
- Continue rounds until 2 pairs remain; play final duel (5 questions per pair; sudden death if tied).

GAME RULES
- Correct answer: chain goes up one step.
- Incorrect answer: all unbanked chain money is lost; next pair takes over on the next question.
- BANK saves the chain to the shared prize fund, then restarts the chain at zero.
- At the maximum step of 5000, the game banks automatically and resets the chain.
- When the clock reaches zero, the round ends. The teacher can also end a round early.
- Eliminated teams are selected by the teacher based on classroom votes, not automatically by the app.
- Final winner is the pair with most correct answers in the head-to-head final.
- Sound needs a click to unlock in some browsers. Press TEST and set system/browser volume appropriately.
- Works entirely offline with no server, internet, external fonts, APIs, student devices or downloads.
- Current game autosaves locally in this browser and can be resumed.

CONTENT
Original English-language practice questions based on Connectivity 5 Unit 10, Global Ties: meanings of phrasal verbs, separability, object pronouns, useful expressions and culture shock. Some questions accept multiple reasonable answers; the teacher decides correctness. The expected answers are shown on the screen after judging and can also be printed from Answer_Key.html.

This is an original classroom adaptation; no official branding, soundtrack or artwork is used.
