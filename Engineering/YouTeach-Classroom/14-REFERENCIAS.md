# 14 — Referencias, alternativas y comprobaciones a realizar
**Proyectos de referencia** (no dependencias elegidas):
- BigBlueButton: https://bigbluebutton.org/ y https://github.com/bigbluebutton/bigbluebutton — plataforma de clase completa; descartada como base por peso/alcance para este proyecto.
- OpenBoard: https://openboard.ch/ — el usuario confirmó que era el programa de Windows que usó; sus pestañas no satisfacen la UX deseada.
- `cracker0dks/whiteboard`: https://github.com/cracker0dks/whiteboard — candidato Node.js; verificar versión, licencia exacta, dependencias y compatibilidad con Android/DOM multimedia.
- WBO/Whitebophir: https://github.com/lovasoa/whitebophir — candidato colaborativo; comprobar licencia AGPL y obligaciones aplicables.
- Socket.IO: https://socket.io/docs/v4/ — salas, eventos, transporte y reconexión.
- HTML Canvas/Pointer Events: https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events — entrada stylus/dedo/ratón.
- HTMLMediaElement: https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement — controles de reproducción local.
- YouTube IFrame API: https://developers.google.com/youtube/iframe_api_reference — límites y eventos del reproductor embebido.
- Autoplay policy: https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay — restricciones de inicio con audio.
- WebRTC: https://webrtc.org/ — solo para posible videollamada futura; no confundir con sincronía de clips.

- `docs/superpowers/specs/2026-08-27-support-meter-teacher-monitor-design.md`: patrón de mosaico, foco, reingreso y permisos, a usar como inspiración, sin editar.
