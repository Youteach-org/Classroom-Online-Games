# Verb Runner character assets

Production character target:

- `red-runner.glb` — approved red runner based on the ALEX visual reference.

Rules:

1. The asset must be a real 3D model, not a screenshot or static render.
2. Review it first in `Verb-Runner/character-viewer.html` with orbit/zoom controls.
3. Matching only the red palette is not sufficient. Silhouette, hair, face, proportions, clothing and overall identity must match the approved red reference.
4. No backpack.
5. Prefer one self-contained GLB for the web build.
6. Do not replace the gameplay runner with the model until visual approval and basic performance checks are complete.
